# JoystickandGamepad
Helps Visualise Gamepads and Logitech 3D pro joystick. Used for testing hardware to software mapping for stick based devices. 
Demonstrates two different methods -

1) [PlayStation](https://pathakdivya.github.io/JoystickandGamepad/Playstation%20visualizer/playstation-gamepad-visualiser.html) relies on image assets 
2) [Xbox](https://pathakdivya.github.io/JoystickandGamepad/Xbox%20Visualizer/xbox-visualiser.html) is an svg file
