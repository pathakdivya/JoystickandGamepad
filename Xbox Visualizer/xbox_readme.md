# Xbox Gamepads (or any xinput based gamepad devices) 


### **Xbox Visualizer**
 
```
Controller Input (Gamepad API)
  ↓
SVG Element Updates (Inline graphics)
  ↓
Real-Time Rendering:
  • Button glow effects
  • Stick motion tracking
  • D-Pad direction highlights
  • Center button animation
```
 
**Key Features:**
- Pure SVG controller diagram (no images)
- Lightweight and fast rendering
- Self-contained single file
- CSS-driven visual effects
